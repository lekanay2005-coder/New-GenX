
# NEW-GENX V2

Cyberpunk Web3 Marketplace built with:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Solana Wallet Ready

## Run

```bash
npm install
npm run dev
```

## Features

- Futuristic Landing Page
- Wallet Connect UI
- Product Marketplace
- Seller Dashboard UI
- Responsive Design
- Neon Cyberpunk Theme
